# cep_lint check_file_topology

Function ID: CS-a37 (domain CS)

## Tier 1: Beginner

Checks file line limits by declared class and rejects junk-drawer names.

## Tier 2: Silicon Reality

Class-based limits come from the configuration with a default fallback; junk names are a case-insensitive substring ban per the topology rules.

## Silent Failure Checklist

1. Fallbacks: none.
2. Truncation: none.
3. Wrapping: none.
4. Error codes: n/a; findings only.
